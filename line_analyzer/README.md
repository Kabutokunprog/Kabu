# ふたりの記録帳（LINEトーク分析アプリ）

LINEのトーク履歴を最初から最後まで読み込み、月ごとに二人の気持ちややりとりの変化をまとめ、
あとから自由に質問できるようにするアプリです。株アプリなど、このリポジトリの他のプログラムとは関係のない、独立したアプリです。

## 大事なこと（プライバシー）

- 会話データは **このフォルダには保存されません**。あなたのホームフォルダの
  `~/.line_analyzer_private/` という隠しフォルダに保存され、あなただけが読める設定になります。
- LINEのテキストファイルを、このリポジトリのフォルダにコピーしないでください
  （念のため `.txt` などはGitHubに上がらないよう設定済みです）。
- AIは2種類から選べます（あとから切り替えもできます）。
  - **Mac内のAI（標準）**: Ollamaというソフトを使い、会話は一切外に出ません。無料です。
  - **Claude**: 精度が高い代わりに有料で、「圧縮した会話」と「要約」がAnthropic社のAPIに送られます。
- MacBookではFileVault（ディスクの暗号化）をオンにしておくと、さらに安心です。
  保存場所は `LA_HOME=保存したい場所` で変えられます。

## しくみ（トークンを節約する工夫）

1. **取り込み**（AI不使用・無料）: テキストを1通ずつに分けて保存します。
   次回以降は、新しいエクスポートを丸ごと渡しても **まだ無いメッセージだけ** が追加されます。
2. **数値の集計**（AI不使用・無料）: 月ごとの件数、どちらから話しかけたか、返信の速さ、
   愛情表現やネガティブな言葉の頻度、通話時間、深夜のやりとり、隠語の出現回数など。
3. **月ごとの要約**（AI使用・1回だけ）: 会話を圧縮して月ごとに1回だけAIに読ませ、
   出来事・行った場所・お互いの気持ち・点数（愛情・満足度・親密さ・衝突・夜の満足度）を保存します。
   **一度要約した月は保存されるので、追加の取り込み後も新しい月・増えた月だけ** が作り直されます。
4. **質問**（AI使用・少量）: 質問文から期間とキーワードを読み取り、その期間の
   「要約＋数値＋関係する会話の抜粋」だけをAIに渡します。全文は送らないので安く済みます。

## はじめての準備（MacBook）

1. ターミナルを開き、Pythonが入っているか確認します: `python3 --version`（3.10以上が必要）
   古い場合は https://www.python.org/ から最新版を入れてください。
2. このフォルダに移動して、部品を入れます:
   ```
   cd このフォルダの場所/line_analyzer
   python3 -m pip install -r requirements.txt
   ```
3. **Mac内のAIを使う場合（標準）**:
   1. https://ollama.com からOllamaをダウンロードして、アプリケーションフォルダに入れ、起動します。
   2. ターミナルでAI本体を取得します（数GB・初回だけ）: `ollama pull qwen3.5:9b`
   3. ほかの候補（メモリ16GBで動くもの）: `gemma4:12b`、`qwen3:8b`。
      変えるときは `python3 la.py settings --set ollama_model=gemma4:12b`
4. **Claudeも使う場合**: AnthropicのAPIキーを設定します（https://console.anthropic.com/ で発行）:
   ```
   export ANTHROPIC_API_KEY="sk-ant-..."
   ```
   毎回入力しないで済むよう、`~/.zshrc` の最後にこの1行を書いておくと便利です。

## 使い方

### 1. LINEのトーク履歴を取り込む
LINEアプリでトークを開き →「設定」→「トーク履歴を送信」で出したテキストファイルを使います。
```
python3 la.py import ~/Downloads/[LINE]花子とのトーク.txt
```
初回は、どの名前があなたでどれがお相手かを番号で聞かれます。
後日、新しいトーク履歴を出したら同じコマンドで取り込むだけです（増えた分だけ追加されます）。

### 2. 月ごとの要約を作る
```
python3 la.py summarize
```
先に **料金の見積もり** が表示され、「y」と入力すると実行します。見積もりだけ見たいときは `--dry-run`。

### 3. 質問する
```
python3 la.py ask "2026年の4-6月くらいの会話を振り返って"
python3 la.py ask "鎌倉にはいつ行ったっけ？"
python3 la.py ask "彼女の彼に対する愛情度合いは？最近どう変わった？"
python3 la.py ask "去年の夏と今年の夏で満足度はどう違う？"
```
続けて何度も聞きたいときは `python3 la.py chat`（前の質問の流れを覚えています）。
- 回答は「ノリが良くて優しい、色っぽいお姉さん」の口調です（辛口なし・下ネタにも率直にノッてくれます。
  利用規約に触れる生々しい描写だけは避けます）。Claudeに断られたときは、質問を穏やかな言い回しに自動で変えて聞き直します。
  丁寧な説明に戻すときは `python3 la.py settings --set persona=plain`（お姉さんに戻すときは `persona=onee`）。
  月ごとの要約は記録なので、落ち着いた書き方のままです。
- お姉さんは **会話を覚えています**。chat を開き直しても前回の続きから話せて、話すたびに「キミについて覚えておくこと」を
  メモにまとめ直します。話した回数で「仲良しレベル」が上がり、だんだん親しい距離感になります。
  記憶を見る: `python3 la.py memory` ／ 全部忘れてもらう: `python3 la.py memory reset`
  （記憶は秘密フォルダの memory.json と talk.db に保存されます）
- 期間は「2026年4-6月」「2026年4月」「2026年夏」「去年」「今年」「先月」「最近」「最初の頃」などが分かります。
- より細かく知りたいときは `--raw` を付けると、その期間の会話全文もAIに渡します（料金は増えます）。
- `--dry-run` を付けると、AIに送る内容とトークン量だけを確認できます（無料）。

### 4. 二人の言葉（隠語）を教える
```
python3 la.py glossary add "ぽんぽこ" "夜の営みのこと" intimacy
python3 la.py glossary suggest     # よく出る言葉から候補をAIに推測してもらう
python3 la.py glossary list        # 一覧（？は推測でまだ未確認のもの）
python3 la.py glossary confirm ぽんぽこ
python3 la.py glossary review      # 推測の言葉を1つずつ「正しい／意味を直す／消す」で確認
python3 la.py glossary edit        # 一覧の画面で、まとめて編集（おすすめ）
```
一覧の画面では、言葉ごとに次の項目を決められます（Mac内だけで動き、外には送りません）。
- **本当の意味（自分用）**: 直接的な言葉でOK。Macの中だけに保存し、AIには送りません。
- **AIに伝える意味**: やわらかい言い方。AIにはこちらだけを渡します（直接的すぎるとAIが回答を止めることがあるため）。
- **重要度**（★1〜5）: 高いものから優先してAIに伝えます。
- **セクシー度**（0〜5）: 月ごとの集計の「色っぽさ」（言葉のセクシー度の合計）に使います。
カテゴリ: `intimacy`(性生活) `affection`(愛情表現) `nickname`(呼び名) `place`(場所) `health`(体調) `other`
要約を作るときにもAIが新しい言葉を見つけると「？（推測）」として自動で辞書に追加されます。
辞書を直したあと、過去の要約にも反映したいときは `python3 la.py summarize --force`。
性生活についての分析は、露骨な表現ではなく「深いつながりを好む傾向」「満足している様子」のような穏やかな表現で書かれます。

### 5. キーワードで探す（AI不使用・無料）
```
python3 la.py search 鎌倉
python3 la.py search 鎌倉 --from 2026-04 --to 2026-06
python3 la.py search 鎌倉 大仏 -C 2     # 両方を含む発言を、前後2通ずつ表示
```
当たった発言には ▶ が付きます。辞書に登録した言葉で探すと、その意味も表示されます。

### 6. AIを切り替える・読み比べる
```
python3 la.py settings --set backend=claude    # ふだん使うAIをClaudeに（戻すときは backend=ollama）
python3 la.py ask "最近どう？" --ai claude      # 今回だけClaudeを使う
python3 la.py trial 2026-04                    # 1か月分を両方で要約し、読み比べ用ファイルを作る
```
`trial` は保存済みの要約を変えません。結果は秘密フォルダの `reports/trial_月.md` にできます。

### 7. MedicationReminderの記録と合わせる
MedicationReminderから記録をCSVかJSONで書き出して取り込みます。
```
python3 la.py health-import ~/Downloads/medication.csv
python3 la.py correlate
```
列名（日時・種類・程度・メモなど）は自動で判断し、「交渉」「鈍痛」「生理」「服薬」などに分類します。
`correlate` は、記録のあった日の **前・当日・後** で、会話の量・愛情表現・ネガティブな言葉が
普段とどう違うかを数字で比べます（AI不使用）。記録は月ごとの要約や質問の回答にも使われ、
「会話 × 時間 × 体の記録」をまとめて分析できます。
※ うまく読み取れない場合は、書き出したファイルの最初の数行（中身は伏せて列名だけ）を教えてください。対応させます。

### その他
| コマンド | 内容 |
|---|---|
| `python3 la.py stats` | 月ごとの数値の表（無料） |
| `python3 la.py report` | 月ごとの要約を1つの読み物にまとめる（秘密フォルダの reports/report.md） |
| `python3 la.py cost` | これまでのAI使用量と料金の目安 |
| `python3 la.py settings` | 設定の確認 |
| `python3 la.py settings --set model_summary=claude-haiku-5-5` | 要約を安いモデルに変える（料金が約40分の1。精度は少し下がります） |
| `python3 la.py settings --set me_label=僕 partner_label=かなちゃん` | 結果での呼び方を変える |

## 料金・時間の目安
Mac内のAIは0円です。代わりに、100万文字ほどの会話だと最初の要約に数時間かかります
（実行前に時間の目安が表示されます。途中で止めても、終わった月は保存されます）。

Claudeの場合、LINEの文字数がおよそ100万文字（数万行）なら、最初の要約は
- 標準設定（claude-opus-5-5）: 数ドル程度
- 安い設定（claude-haiku-5-5）: 数十セント程度

質問1回は、通常1〜2万トークン程度（数セント）です。実行前に必ず見積もりが表示されます。
