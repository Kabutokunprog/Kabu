# 勤怠記録アプリ（改良版）設置手順

今のスプレッドシートと記録（`2026-11` のような月別シート）はそのまま使えます。

## 1. プログラムを入れ替える（5分）
1. 今のスプレッドシートを開き、メニュー「拡張機能」→「Apps Script」を開きます。
2. 左側の「コード.gs」の中身をすべて消し、このフォルダの `コード.gs` の中身を貼り付けます。
3. 左上の「＋」→「HTML」を押し、名前を **`Index`** にします（大文字の I）。
   中身をすべて消し、このフォルダの `Index.html` の中身を貼り付けます。
4. 💾（保存）を押します。

## 2. 今までのURLのまま更新する
1. 右上「デプロイ」→「デプロイを管理」を押します。
2. ✏️（編集）を押し、「バージョン」を **「新バージョン」** にして「デプロイ」。
   → いつものURL・ホーム画面のアイコンのまま新しい画面になります。
3. 初回は「アクセスを承認」の画面が出ます。自分のアカウントを選んで許可してください
   （メールを送る機能が増えたため）。

## 3. 時給を直す
1. アプリの「⚙️設定」→「時給」で、**時給が変わった日** と **新しい時給** を入れて登録します。
2. それより前の日は元の時給、後の日は新しい時給で、過去の記録も自動で計算し直されます。
   （スプレッドシートに「時給履歴」シートができ、各月のシートに「時給(円)」列が増えます）

## 4. 金曜日のお知らせをオンにする
「⚙️設定」→「お知らせメール」→「オンにする」。「テスト送信」で届くか確認できます。

## 使い方
- **⏱打刻**：「出勤」「退勤」を押すだけ。出勤を押さなければ今までどおり 9:00 出勤で計算します。
- **📅勤怠表**：月ごとの一覧。行をタップで修正・削除、「＋追加」で押し忘れを登録。
- **📊振り返り**：年ごとの月別グラフ・合計、上限を超えた週。過去の年も選べます。
- **💴税金**：今年の収入と「年収の壁」までの残り、週20時間の説明。
