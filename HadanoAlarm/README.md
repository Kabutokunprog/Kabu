# 秦野アラーム（乗り過ごし防止アプリ）

小田急線で東京方面から帰ってくるとき、秦野駅に近づいたら**振動だけ**（音なし）で知らせる iPhone アプリです。

## どう動くか

| いつ | 何をする |
|---|---|
| ふだん | GPS は使いません。iPhone が省エネで「伊勢原駅・鶴巻温泉駅の付近に入ったか」だけを見張ります |
| 設定した曜日・時間帯に伊勢原付近へ入ったとき | GPS を使い始めます（この時点では振動しません） |
| 東海大学前を過ぎ、秦野まで 3.5km（約3分前） | ブルッ（約20秒続いて自動で止まる） |
| 秦野まで 2km（約1分半前） | ブルッブルッ（約20秒） |
| 秦野まで 800m（約50秒前） | ブルッブルッブルッ（約30秒） |
| 秦野で降りて6分たったとき | 保護者へ「秦野に着きました」と通知（オフにもできます）→ GPS を止める |
| 秦野を過ぎて渋沢方面へ走っていったとき | 長めの振動 ＋ 保護者へ「乗り過ごし注意」と通知（今いる場所の地図つき） |

- 電波の具合で位置が飛んでも、3回とも順番に（10秒以上あけて）知らせます。
- 振動は「止める」ボタン（通知またはアプリの画面）で途中で止められます。
- 曜日（初めは月〜金）と時間帯（初めは 17:00〜20:00）はアプリの画面で変えられます。
- 東京方面へ向かうとき（秦野から離れていくとき）は何もせず、すぐ GPS を止めます。

## Mac での準備（最初の1回だけ）

### 1. ファイルを Mac に持ってくる
1. Mac のブラウザ（Safari など）で GitHub にログインした状態で、次のアドレスを開きます。ZIP ファイルのダウンロードが始まります。
   `https://github.com/Kabutokunprog/Kabu/archive/refs/heads/claude/hadano-alarm.zip`
2. 「ダウンロード」フォルダにできた ZIP をダブルクリックして開きます。
3. 開いたフォルダの中の **`HadanoAlarm`** フォルダを、デスクトップなど好きな場所に置きます。

### 2. Xcode で開く
1. App Store から **Xcode**（無料）を入れておきます（最新版にしてください）。
2. `HadanoAlarm` フォルダの中の **`HadanoAlarm.xcodeproj`** をダブルクリックします。

### 3. 署名（自分のアプリだという登録）
1. 左の一覧のいちばん上の青いアイコン「HadanoAlarm」をクリック。
2. 真ん中の「TARGETS」→「HadanoAlarm」→ 上のタブ「**Signing & Capabilities**」を開きます。
3. 「**Team**」で、ご自身の Apple Developer アカウント（チーム）を選びます。
4. 「Bundle Identifier」に赤いエラーが出たら、`jp.kabutokun.hadano-alarm` の後ろに `2` を足すなど、世界で1つの名前に変えてください。

### 4. まずはご自身の iPhone で試す（おすすめ）
1. iPhone を USB ケーブルで Mac につなぎます。
2. Xcode の上部中央で、つないだ iPhone を選びます。
3. 左上の ▶（再生ボタン）を押すと、iPhone にアプリが入ります。
   - 初回は iPhone の「設定 → 一般 → VPN とデバイス管理」で開発元を信頼する必要がある場合があります。
   - 「デベロッパモード」をオンにするよう言われたら、「設定 → プライバシーとセキュリティ → デベロッパモード」をオンにします。

### 5. TestFlight でお嬢さんに配る
1. [App Store Connect](https://appstoreconnect.apple.com) →「アプリ」→「＋」→「新規 App」。
   - プラットフォーム：iOS ／ 名前：秦野アラーム（他の人と重なるときは少し変える）
   - バンドル ID：手順3で決めたもの ／ SKU：`hadano-alarm` など何でも可
2. Xcode に戻り、上部中央の機種選びで「**Any iOS Device (arm64)**」を選びます。
3. メニュー「**Product → Archive**」。数分待つとウィンドウが開きます。
4. 「**Distribute App**」→「**TestFlight & App Store**」→ あとは「Distribute」「Upload」で進めます。
5. 10〜30分ほどで App Store Connect の「TestFlight」タブにビルドが出てきます。
6. テスターの追加：
   - **内部テスター**（審査なし・すぐ使える）：App Store Connect の「ユーザとアクセス」でお嬢さんの Apple ID を「ユーザ」として招待 → TestFlight の「内部テスト」グループに追加。
   - **外部テスター**（メールアドレスだけで招待できる）：初回だけ Apple の簡単な審査（1日ほど）があります。
7. お嬢さんの iPhone に「TestFlight」アプリを入れ、届いた招待からインストールします。

> 2回目以降にアプリを更新するときは、Xcode の「TARGETS → General」の **Build** の数字を1つ増やしてから Archive してください。

## お嬢さんの iPhone での設定

アプリを開いて、画面の「はじめに許可してください」を2つとも緑にします。

1. **位置情報**：「許可する」→「アプリの使用中は許可」→ もう一度出る確認で「**常に許可に変更**」。
   - 「設定 → 秦野アラーム → 位置情報」で「**常に**」と「**正確な位置情報：オン**」になっていれば OK です。
2. **通知**：「許可」を選びます（振動を止めるボタンを出すため）。
3. 「設定 → サウンドと触覚 → 触覚」が「**常に再生**」になっているか確認します（消音モード中でも振動させるため）。
4. 「設定 → アクセシビリティ → タッチ → **バイブレーション**」がオンか確認します。
5. **アプリを上にスワイプして終了しない**でください（終了すると見張りが止まることがあります）。
6. 画面の「テスト」で振動を試し、**画面を閉じても振動が続くか**確認してください。

## 保護者のスマホでの設定（乗り過ごし通知）

1. 無料アプリ「**ntfy**」を App Store（Android は Google Play）から入れます。
2. お嬢さんの iPhone のアプリ画面「保護者への通知」にある **トピック名**（`hadano-` で始まる文字）を確認します（「コピー」でLINE などで送れます）。
3. ntfy アプリで「＋」→ そのトピック名を入力して登録します（サーバーは `ntfy.sh` のままで OK）。
4. お嬢さんのアプリで「保護者へテスト通知を送る」を押し、届けば完了です。

> トピック名を知っている人は誰でも通知を受け取れるので、家族以外には教えないでください。

## うまく動かないとき

アプリの「動作の記録」に、いつ見守りを始めたか・何回目の振動を出したか・通知を送れたか、が残ります。その画面のスクリーンショットを Claude に見せてもらえれば原因を調べられます。

## 中身（開発者向け）

| ファイル | 役割 |
|---|---|
| `HadanoAlarm/TripLogic.swift` | 距離から「何回目を鳴らすか・乗り過ごしか・降りたか」を決める計算（iPhone の機能に頼らない） |
| `HadanoAlarm/TripMonitor.swift` | 場所の見張り（ジオフェンス）と GPS の開始・停止 |
| `HadanoAlarm/Alarmer.swift` | 振動のリズムと「止める」通知 |
| `HadanoAlarm/ParentNotifier.swift` | 保護者への通知（ntfy.sh） |
| `HadanoAlarm/AppSettings.swift` | 曜日・時間帯などの設定 |
| `HadanoAlarm/ContentView.swift` | 画面 |
| `Tests/main.swift` | 判定のテスト：`swiftc HadanoAlarm/TripLogic.swift Tests/main.swift -o /tmp/t && /tmp/t` |

距離や秒数を変えたいときは `TripLogic.swift` の `TripRules`、振動のリズムや長さは `Alarmer.swift` の `AlarmKind` を変えます。
