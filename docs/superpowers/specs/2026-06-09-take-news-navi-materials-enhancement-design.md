# TAKE NEWS NAVI v3 — 素材・材料メーカー強化 設計書

**日付:** 2026-06-09  
**対象ファイル:** Google Apps Script（GAS）版 TAKE NEWS NAVI v3  
**目的:** 日本の素材・材料メーカーに関するニュースの取りこぼしを減らす

---

## 背景と課題

現行システムは Google News RSS + Gemini 短評生成で毎朝5時に HTML メールを配信する。構成は3部（トップニュース / マーケット / 関心ジャンル）。

**課題:** 追いたい日本の素材・材料メーカー（DNP、レゾナック、JSR、住友化学、AGC、信越化学、日東電工、リンテック、富士フイルム）のニュースが取りこぼされている。原因は2つ。

1. 企業名が `INTEREST_QUERIES` に入っていない
2. 日本の B2B 専門メディア（MONOist、EE Times Japan、日刊工業新聞）の記事が Google News RSS に乗りにくい

---

## 設計概要

既存コードへの追加変更は3点のみ。アーキテクチャは変えない。

### 変更1: 企業名クエリの追加

`INTEREST_QUERIES` に以下の8エントリを追加する（priority: `'high'`）。

| クエリ | 狙い |
|---|---|
| `DNP 大日本印刷 フィルム 材料` | 機能フィルム・印刷材料 |
| `レゾナック 半導体材料` | CMP スラリー・封止材 |
| `JSR 半導体 フォトレジスト` | フォトレジスト・合成ゴム |
| `住友化学 素材 機能材料` | 偏光フィルム・農薬原料 |
| `AGC ガラス フッ素 材料` | フッ素樹脂・ディスプレイガラス |
| `信越化学 シリコン 半導体` | シリコンウエハー・シリコーン |
| `日東電工 光学フィルム テープ` | 偏光板・医療テープ |
| `リンテック 粘着 半導体` | ダイシングテープ・剥離紙 |

富士フイルムは既存クエリに含まれているため追加不要。

### 変更2: 専門メディア RSS「第4部」の追加

化学工業日報は有料のため除外。以下3媒体を直接購読する。

| 媒体 | RSS URL |
|---|---|
| MONOist | `https://monoist.itmedia.co.jp/rss/monoist_all.xml` |
| EE Times Japan | `https://eetimes.itmedia.co.jp/rss/eetimelj.xml` |
| 日刊工業新聞 | `https://www.nikkan.co.jp/rss/news.rss` |

- 各媒体から最大5件、直近48時間フィルタ
- 既存の `fetchFeed_()` をそのまま流用
- メール本文に「第4部: 素材・材料 専門メディア」セクションとして追加

### 変更3: Gemini 関連度スコアリングの追加

Gemini の短評生成プロンプトを拡張し、各記事に **関連度スコア（1〜5）** を付与させる。

**スコア基準:**
- **5** = 追いたい日本メーカー（DNP/レゾナック/JSR/住友化学/AGC/信越化学/日東電工/リンテック/富士フイルム）の具体的な動向
- **4** = 日本の素材・材料産業に直結する情報
- **3** = 関連技術・市場の動向
- **2** = 周辺情報・関連性が薄い
- **1** = ほぼ無関係

**フィルタリング:** スコア ≤ 2 の記事は `INTEREST_QUERIES` と専門メディアセクションの表示から除外する。トップニュースとマーケットはフィルタなし（除外すると重要ニュースを見逃す可能性があるため）。

**Gemini 出力フォーマット変更:**

```
// 変更前
["短評0", "短評1", ...]

// 変更後
[{"comment": "短評0", "score": 4}, {"comment": "短評1", "score": 2}, ...]
```

フォールバック: JSON パース失敗時はスコアなしで短評のみ表示（既存挙動を維持）。

## メール構成（変更後）

```
第1部 本日のトップニュース（変更なし）
第2部 マーケット（変更なし）
第3部 あなたの関心ジャンル（企業クエリ8社追加でカバレッジ強化）
第4部 素材・材料 専門メディア ← NEW
フッター
```

- 他ファイルへの変更なし

---

## エラーハンドリング方針

- 専門メディア RSS が取得できない場合は該当媒体をスキップ（既存 `fetchFeed_` の挙動）
- スコアリング JSON パース失敗時は既存の短評フォールバックを維持
- スコアなし記事は表示側でスコア条件を無視して表示する
