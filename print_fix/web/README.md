# くっきり印刷

スキャンしたPDF(Genius Scan など)を、レーザープリンタでかすれにくくして印刷するWebアプリです。

1. PDFを開く
2. 解析(かすれやすさをページごとに表示)
3. 印刷設定(2アップ / 余白カット / 文字の太さ / 色文字の扱い / 画質)
4. 印刷用PDFを作って印刷・保存

処理はすべてブラウザの中で行い、PDFは外部に送信しません。
このフォルダをそのまま静的サイトとして公開すれば動きます(サーバー側の処理は不要)。
`lib/` には pdf.js 3.11.174 と pdf-lib 1.17.1 を同梱しています(ライセンスは同じフォルダ内)。

## 公開先

https://kukkiri-print.vercel.app (Vercel プロジェクト kukkiri-print)

公開版はライブラリを cdnjs から読み込みます(`lib/` 版と同じバージョン)。
